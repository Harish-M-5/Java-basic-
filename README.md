# 🧩 **Java Basics – Explanation**

### **1️⃣ Variables**
Stores data in memory.

### **2️⃣ Data Types**
Defines type of variable  
(int, double, float, boolean, char, String)

### **3️⃣ Operators**
Arithmetic, Logical, Comparison operators.

### **4️⃣ Conditional Statements**
if, else if, else, switch

### **5️⃣ Loops**
for, while, do-while

### **6️⃣ Arrays**
Stores multiple values of same type.

### **7️⃣ Strings**
Text manipulation using String class.
